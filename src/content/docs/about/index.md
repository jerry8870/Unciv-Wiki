Unciv Wiki is a bilingual community guide with beginner articles, a Gods & Kings database and Unciv4iOS achievement documentation. Site maintainers curate it; it is not official Civilization documentation.

## Sources and baseline

Game data is pinned to **4.21.20 (1293)** and public game commit `5fa2f57457755c403ea82cc21fec9e617feaf2d0`. V3 achievements use the corresponding 1293 rules and matching English and Simplified Chinese text. The website contains only the needed data, text and icon snapshots, not private game code or release records.

Generated pages use a versioned snapshot whose manifest records source commits and SHA-256 checksums. Editorial guides are written against that baseline and distinguish suggestions from source facts. Page update dates represent content changes, not build times.

## Verification boundaries

Database values describe base rules; they do not simulate a save's final costs. Achievement conditions come from the rules, not a claim that every medal was reproduced on an iOS device. Check TestFlight for build 1293 distribution and future versions.

Suggest corrections in the [wiki repository](https://github.com/jerry8870/Unciv-Wiki), with a page link, version and reproducible evidence. See [Credits](/credits/) and [Privacy](/privacy/).

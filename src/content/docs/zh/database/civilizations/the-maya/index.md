# 玛雅

**领袖**：帕卡尔

**独特能力**：长历法

## 独特能力

- 研究玛雅长历法后，每神学结束时(每394年)得到一个免费的伟人，每种伟人只能选择一次。
- 一旦长历法激活，世界屏幕上的年份将显示为传统的玛雅长计数。

- 丛林

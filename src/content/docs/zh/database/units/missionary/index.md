# 传教士

## 属性

| 属性 | 数值 |
| --- | --- |
| 类型 | Civilian |
| 移动力 | 4 |

## 能力

- 消耗4移动力2次在单位被消耗后可以传播宗教
- 可进入外国未开放边界的领土，在外国领土结束回合时失去250宗教力量
- 信仰可以使用每座主流宗教为主要宗教的城市购买
- 视野-1
- 不可建造或训练
- 宗教单位
- 若启用宗教可用

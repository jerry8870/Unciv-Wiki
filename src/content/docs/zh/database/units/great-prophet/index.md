# 大先知

## 属性

| 属性 | 数值 |
| --- | --- |
| 类型 | Civilian |
| 移动力 | 2 |

## 能力

- 通过消耗此单位当未进行执行其他行动时可立即建造圣地地块改良
- 消耗2移动力4次在单位被消耗后可以传播宗教
-  传播宗教时消除异端
- 通过消耗此单位当未进行执行其他行动时可创建一个宗教
- 通过消耗此单位当未进行执行其他行动时可增强一个宗教
- 是先知类伟人的一部分
- 该单位从先知名称库中获得一个名字
- 可进入外国未开放边界的领土
- 视野-1
- 信仰类伟人
- 不可建造或训练
- 宗教单位
- 若启用宗教可用
- 使其他文明的城市信仰你的宗教，甚至消灭其他宗教

## 规则与效果

- 可以加速建筑物的建造
- 通过消耗此单位可立即建造制造中心地块改良
- 是伟人类伟人的一部分
- 该单位从工程师名称库中获得一个名字
- 产能类伟人
- 不可建造或训练
- 不可捕获

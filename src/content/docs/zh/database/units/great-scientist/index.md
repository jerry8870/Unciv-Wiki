## 规则与效果

- 可以加速科技研究
- 通过消耗此单位可立即建造学院地块改良
- 是伟人类伟人的一部分
- 该单位从科学家名称库中获得一个名字
- 科研类伟人
- 不可建造或训练
- 不可捕获

## 能力

- 在+15格内军事 陆地单位2%战斗力
- 通过消耗此单位可立即建造军事要塞地块改良
- 令陆地单位可通过战斗获得
- 是一般类伟人的一部分
- 该单位从一般名称库中获得一个名字
- 战争类伟人
- 不可建造或训练
- 不可捕获

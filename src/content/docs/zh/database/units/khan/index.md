# 可汗

## 属性

| 属性 | 数值 |
| --- | --- |
| 类型 | Civilian |
| 移动力 | 5 |
| 替代 | 大军事家 |
| 专属文明 | 蒙古 |

## 能力

- 在+15格内军事单位2%战斗力
- 所有相邻单位在恢复时额外+15生命值
- 恢复时额外恢复+15点生命值
- 通过消耗此单位可立即建造军事要塞地块改良
- 令陆地单位可通过战斗获得
- 是一般类伟人的一部分
- 该单位从可汗名称库中获得一个名字
- 战争类伟人
- 不可建造或训练
- 不可捕获

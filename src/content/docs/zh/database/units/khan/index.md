## 规则与效果

- 在2格内军事单位+15%战斗力
- 所有相邻单位在恢复时额外+15生命值
- 恢复时额外恢复+15点生命值
- 通过消耗此单位可立即建造军事要塞地块改良
- 令陆地单位可通过战斗获得
- 是一般类伟人的一部分
- 该单位从可汗名称库中获得一个名字
- 战争类伟人
- 不可建造或训练
- 不可捕获

# 审判官

## 属性

| 属性 | 数值 |
| --- | --- |
| 类型 | Civilian |
| 移动力 | 3 |

## 能力

- 阻止紧邻城市的宗教传播
- 在友善地块上一次在单位被消耗后可以驱除城市异教
- 信仰可以使用每座主流宗教为主要宗教的城市购买
- 视野+1
- 若启用宗教可用
- 不可建造或训练
- 宗教单位

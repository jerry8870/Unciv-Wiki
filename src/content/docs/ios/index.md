**Unciv4iOS is a community iOS port of Unciv.** Unciv is an open-source strategy game inspired by Civilization V. This wiki documents the port and its Gods & Kings data; it is not an official Civilization product.

<a id="tf-ios-en" href="https://testflight.apple.com/join/XSgMMQjt">Open the Unciv4iOS TestFlight invitation</a>

## Install the beta

1. Open the invitation on your iPhone or iPad. Follow Apple's prompt to install TestFlight if needed.
2. Return to the invitation and follow the acceptance and installation steps shown by TestFlight.
3. Before installing or updating, read the test notes in TestFlight.
4. Launch the game and use the [first-game guide](/getting-started/) to start a simple match.

A full, closed or unavailable beta may prevent joining. Check the TestFlight invitation page to see whether installation is available.

## Device requirements

The source configuration declares **iOS 15.0 or later**, iPhone and iPad device families, and an ARM64 device build. These are source configuration facts, not a performance guarantee on every supported device. TestFlight displays the current install eligibility for your device.

See the [change notes](/changelog/) for more information.

## Achievements and local records

The game has [40 achievements worth 600 points](/achievements/). Records are local to the device and do not sync through Game Center or iCloud. Read the qualifying-game rules before starting an achievement attempt.

## Feedback and project relationship

Report reproducible problems at [Unciv4iOS issues](https://github.com/jerry8870/Unciv4iOS/issues), including your device and the steps that led to the problem. Include a screenshot or save only when you are comfortable sharing it. The upstream game is [Unciv](https://github.com/yairm210/Unciv); the community port is [Unciv4iOS](https://github.com/jerry8870/Unciv4iOS).

No App Store listing or unverified gameplay screenshot is presented here. The TestFlight invitation is the installation route documented by this page.

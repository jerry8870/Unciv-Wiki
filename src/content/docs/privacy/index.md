## Analytics is off by default

The site loads Google Analytics only when a GA4 measurement ID is configured **and you explicitly accept**. An unconfigured, undecided or rejected state does not load GA4. Rejecting analytics does not block reading, search or TestFlight links.

After acceptance, GA4 can record page views and outbound clicks through enhanced measurement, including link URLs, domains and entry IDs. The site does not send a duplicate TestFlight click event, collect game saves or achievement progress, or equate clicks with installations. Google processes the network request data it receives; see [Google's Privacy Policy](https://policies.google.com/privacy).

## Accept, reject or withdraw

Analytics preferences appear at the bottom of every page. Browser local storage remembers acceptance or rejection; this choice does not sync across devices. “Withdraw consent” disables subsequent tracking, clears accessible GA cookies for this site and reloads the page to unload the script. Withdrawal does not delete data already sent to the analytics property.

If browser storage is unavailable, a choice applies only to the current page. A failed analytics script does not prevent normal browsing or link navigation.

## Hosting and external services

GitHub Pages hosts this site and may process request logs needed to operate its service. Search uses the site's generated Pagefind index. Following TestFlight, GitHub or another external link brings you under that service's privacy rules.
